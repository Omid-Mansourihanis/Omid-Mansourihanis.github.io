US Census Block Dataset Builder

Pick a state → county → (optional) tract. The builder generates a reproducible, block-level urban-analysis dataset (Census + OSM + buildings + GHSL) in Google Colab.

Leave on “all tracts” to build the whole county. Choosing one tract makes a small, fast test dataset.

Your configuration token

Then:

  1. Open the builder notebook in Google Colab ↗
  2. Paste the token into the first cell where it says CONFIG_TOKEN = "..."
  3. Add your free Census API key, then run all cells.
  4. The dataset (GeoPackage + CSV) downloads automatically when finished.
Whole-county builds download several GB (GHSL + building footprints) and take 10–30 min on Colab. A single-tract build is a good first test.

What you get

One table for the county you choose, with one row per 2020 census block and several hundred columns from different sources, already joined on the block GeoID. Downloading, cleaning and merging these sources by hand usually takes days; here it takes a few clicks and one Colab run, and anyone who picks the same county gets the same table.

Files

  • GeoPackage: block polygons with every column; opens in ArcGIS Pro, QGIS or GeoPandas.
  • CSV: the same table without geometry, for Excel, R or machine-learning models.
  • Metadata CSV: the source and native geography of each column, for methods sections and reproducibility.

Useful for

  • Urban planning research: walkability, access to services, spatial equity, site selection.
  • Transportation and safety: road-network features next to population characteristics.
  • Machine learning: a ready feature table keyed on GeoID, easy to join to crashes, crime or housing prices.
  • Comparing cities with identical definitions, e.g. Lubbock and Houston.
  • Teaching: students start analysing instead of wrestling with APIs and file formats.

Keep in mind

  • ACS and DHC values are published for block groups or tracts and are repeated on every block inside them; they do not show differences between neighbouring blocks.
  • ACS margins of error are not included; in small areas they can be large.
  • OpenStreetMap completeness varies by city (sidewalks are often missing).
  • GHSL is a 100 m–1 km grid sampled at each block's centroid, so it is approximate for small blocks.
  • A whole-county build downloads several GB and takes 10–30 minutes; a single-tract build is fast but Census-only.

States and counties: the 3,143 county equivalents of the 2020 Census (bundled with this page). Tracts are listed live from the US Census Bureau API when it is reachable. 50 states and DC are supported.
